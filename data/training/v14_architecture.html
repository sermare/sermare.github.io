Stage 1: Encoder FROZEN

ContactClassifier → single embeddings + contact probabilities
  • Pre-trained ContactClassifier (weights frozen)
  • Output: single (B, L, 128) — per-residue embeddings
  • Output: contact_probs (B, L, L) — pairwise contact map
▼

Stage 2: Pair Stack

SingleToPairV13 + RPE + OPM + Contact Conditioning → 8× EnhancedPairBlock
  • SingleToPairV13 projects single → pair representation
  • LogScaledRPE — 128 bins, max distance 512 residues
  • OuterProductMean — d_opm=32
  • Contact Map Conditioning — gated, d=128
  • 8× EnhancedPairBlock: TriMul (out + in) + AxialBlock
  • Output: pair (B, L, L, 128)
▼

Stage 3: Diffusion Process

Normalize → sample t → add noise to Cα coords
  • Normalize Cα coordinates (center + scale)
  • Sample diffusion timestep t ~ U(0, T)
  • Add Gaussian noise to Cα positions: x_t = α_t x_0 + σ_t ε
  • Note: Noise applied only to Cα — full backbone is derived from frames
▼

Stage 4: Frame Initialization NEW

Peptide Plane Frames from N-CA-C (more stable than CA-triplet Gram-Schmidt)

init_frames_backbone() — uses peptide plane geometry:

e1 = CA→C (normalized)
e3 = (N−CA) × e1 (normalized)
e2 = e3 × e1
  • Peptide plane frame is more geometrically stable than CA-triplet Gram-Schmidt
  • SNR-gated confidence blends noisy vs. ideal frames
  • SLERP interpolation for smooth rotation blending
  • Output: rotation matrices R (B, L, 3, 3) + translations t (B, L, 3)
▼

Stage 5: Self-Conditioning (50%)

50% of training steps condition on previous x̂₀ prediction
  • With 50% probability, run denoiser once to get x̂₀
  • Feed x̂₀ as additional input for the real forward pass
  • At inference: always self-condition (run two passes per step)
▼

Stage 6: IPA Denoiser FrameDenoiserV14

8× IPABlock → x̂₀, R̂, then h passes to BackboneAtomHead
  • 8× IPABlock (same architecture as v13b)
  • Invariant Point Attention over frames + pair representation
  • Predicts: x0_pred (B, L, 3), R_pred (B, L, 3, 3)
  • After final IPA layer: hidden state h (B, L, 512) passes to BackboneAtomHead NEW
▼

BackboneAtomHead NEW in v14

MLP predicts learned offsets from ideal peptide geometry → full [N, CA, C, O] backbone

Architecture:

MLP: 512 → 256 → 256 → 9  (3 atoms × 3 coords)

Outputs: δN, δC, δO (learned offsets from ideal geometry)

Ideal bond lengths:

  • N–CA = 1.458 Å
  • CA–C = 1.523 Å
  • C=O = 1.231 Å

Reconstruction:

pos_atom = t + R @ (ideal_offset + δ)
  • CA always sits at frame origin (no offset learned)
  • Zero-initialized — starts predicting ideal geometry, learns corrections
  • Output: backbone_pred (B, L, 4, 3) — [N, CA, C, O]
▼

Stage 7: Auxiliary Heads

AuxPairStack + OrdinalDistanceHead + RgPredictor
  • AuxPairStack — lightweight pair refinement
  • OrdinalDistanceHead — ordinal distance bins
  • RgPredictor — radius of gyration prediction
