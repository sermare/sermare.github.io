Input Training Batch B × L ▶

Stage 1 Frozen Protein Encoder → (B,L,128) + (B,L,L) ▶
ContactClassifier (frozen, no grad)
  • Pre-trained sequence encoder producing per-residue embeddings
  • Output single: (B, L, 128) — per-residue feature vectors
  • Output contact_probs: (B, L, L) — predicted residue-residue contact probability map
  • All parameters frozen during v13b training — gradients do not flow back
Stage 2 ContactConditionedPairStackV13 → (B,L,L,128) ▶
SingleToPairV13
  • Left & right linear projections of single repr into pair space
  • LogScaledRPE: 128 bins, max_sep=512 — log-scaled relative position encoding
  • Sinusoidal RPE added in parallel
  • Output: initial pair (B, L, L, 128)
OuterProductMean
  • d_opm = 32 — low-rank outer product of single features
  • Added to pair representation
Contact Map Conditioning
  • Gated injection of contact_probs from encoder
  • d_contact_proj = 128 — learned projection + sigmoid gate
EnhancedPairBlock ×8
  • TriangleMultiplicativeUpdate (outgoing) — tri_mul_dim=64
  • TriangleMultiplicativeUpdate (incoming) — tri_mul_dim=64
  • AxialBlock: row + column attention, n_heads=4, d_ffn=512
  • Pre-LayerNorm, residual connections throughout

Final output: pair (B, L, L, 128)

Stage 3 Diffusion Process x0 → xt ▶
Forward Diffusion (training only)
  • Normalize: x0 = (coords − centroid) / coord_scale, where coord_scale = 10.0
  • Sample timestep: t ~ Uniform(0, 1000)
  • Add noise: xt = √ᾱt · x0 + √(1 − ᾱt) · ε,   ε ~ N(0, I)
  • Schedule: Cosine noise schedule (smooth ᾱ decay)
Stage 4 Frame Init + Self-Conditioning → Rigid Frames + Confidence ▶
init_frames(xt, t)
  • Gram-Schmidt orthogonalization on consecutive Cα triplets
  • Builds local coordinate frames: rotation R ∈ SO(3) + translation t ∈ R³
SNR-Gated Confidence
  • snr_high = 1.0 (high confidence threshold)
  • snr_low = 0.2 (low confidence threshold)
  • SLERP toward identity quaternion at low SNR
  • Prevents unreliable frames from dominating at high noise levels
Self-Conditioning (50% prob)
  • With 50% probability during training:
  • Run full denoiser forward pass without gradients → x0,prev
  • Build frames from x0,prev → self_cond_frames
  • These are fed into the main denoiser pass as additional conditioning
  • With 50% probability: self_cond_frames = None (unconditional)

Output: rigid_frames (rotations + translations) + confidence per residue

Stage 5 IPA Denoiser (8 layers) → x0,pred + Rpred ▶
Input Preparation
  • Timestep embedding → d_ipa_hidden = 512
  • Node projection: concat(single, t_emb) → Linear → 512
  • Confidence injection: frame confidence modulates node features
  • Pair enrichment + contact bias from Stage 2
IPABlock ×8
InvariantPointAttention
  • n_heads = 8, n_query_points = 8, d_hidden = 512
  • Scalar attention: q, k, v linear projections
  • Point attention: 3D geometric queries/keys in local frames, forced fp32
  • Pair bias: pair features bias attention logits
  • Output: concat(scalar, point_norms, pair_out) → 1216 → Linear → 512
Transition FFN
  • 512 → 1024 → ReLU → 512 (residual)
FrameUpdate
  • MLP → quaternion (4-dim, normalized) + translation (3-dim)
  • SE(3) compose with current frames

Output: x0,pred (B, L, 3), Rpred (B, L, 3, 3)

Auxiliary Heads
Aux A Distance Head ▶
AuxPairStack

  • OuterProductMean

OrdinalDistanceHead
  • 32 ordinal bins spanning 2–40 Å
  • Output: dist_logits (B, L, L, 32)
  • Output: dist_pred (B, L, L) expected distance
Aux B Rg Predictor ▶
Attention Pooling + MLP
  • Learned attention pooling over single features (B, L, 128) → (B, 128)
  • MLP → softplus activation + 3.0 bias
  • Output: rg_pred (B,) — predicted radius of gyration in Å
