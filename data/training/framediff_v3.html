1. Input

Noised SE(3) frames (R_t, x_t) + timestep t + self-conditioning distogram

The model takes noised rigid-body frames as input. Each residue is represented by an SE(3) frame: a rotation matrix R and translation vector x, corrupted by the forward diffusion process.

  • (R_t, x_t) — noised rotation (IGSO3) + noised translation (VP-SDE)
  • t — continuous diffusion timestep in [0, 1]
  • distogram_sc — self-conditioning: pairwise distance bins from previous denoising pass (50% probability during training)
  • Distogram: 32 bins during training, 22 bins model default
▼

2. Node Init

sin(res_idx, 128) + sin(t, 128) → 3-layer MLP → d_node=256

Per-residue node features are initialized by combining positional encoding and timestep encoding:

  • Sinusoidal positional encoding of residue index: sin_embed(res_idx, d=128)
  • Sinusoidal timestep encoding: sin_embed(t, d=128)
  • Concatenate → 256-dim input
  • 3-layer MLP with ReLU activations → d_node = 256
▼

3. Edge Init

φ(n) + φ(m) + φ(m-n) + φ(t) + φ(disp_sc) → 3-layer MLP → d_edge=128

Edge features encode the pairwise relationship between residues n and m:

  • φ(n), φ(m) — sinusoidal positional encoding of source and target residue indices
  • φ(m-n) — relative sequence offset encoding
  • φ(t) — timestep encoding (broadcast to all edges)
  • φ(disp_sc) — self-conditioning distogram features (pairwise distance bins)
  • All concatenated → 3-layer MLP → d_edge = 128
▼

4. IPA (Invariant Point Attention)

8 heads, 8 query points, 12 value points, d_head=16, AF2-style w_C

Invariant Point Attention from AlphaFold2 — attends over 3D structure using three attention channels merged into one:

  • Scalar attention: standard QKV on node features, d_head=16
  • Point attention: queries and values are 3D points projected into local frames; attention score uses squared distance in global frame
  • Pair bias: edge features added to attention logits
  • 8 heads, 8 query/key points, 12 value points
  • Weight head coefficient: w_C = sqrt(2 / (9 * n_qp)) (AF2-style)
  • Output: concat(scalar_out, point_out_norm, pair_out) → Linear → d_node
▼

5. Transformer

4 heads, 2 layers, 1024 FFN, Pre-LN, operates on (d_node + d_skip)

A standard Pre-LayerNorm Transformer that operates on node features after IPA, with a skip connection from the initial node embedding:

  • Input: cat(h_ipa, h_skip) where h_skip is the initial node embedding
  • Pre-LN normalization (LayerNorm before attention/FFN)
  • 4 attention heads
  • 2 transformer layers
  • FFN hidden dim: 1024
  • Residual connections around each sub-layer
▼

6. Edge Update

Separate src/tgt projections → 3-layer MLP + residual + trailing Linear

Edges are updated using node features from both endpoints:

  • Separate linear projections for source node h_src and target node h_tgt
  • Outer-product-like combination of projected features
  • 3-layer MLP with ReLU activations
  • Residual connection from previous edge features
  • Trailing Linear projection back to d_edge=128
▼

7. Backbone Update

Linear → q=(1,b,c,d) quaternion + translation, re-centering

The backbone update converts node features into frame updates:

  • Linear layer outputs 6 values per residue: 3 for quaternion (b,c,d) and 3 for translation
  • Quaternion is formed as q = (1, b, c, d) — identity-initialized (w=1 fixed)
  • Quaternion → rotation matrix via Rodrigues formula
  • Frame update: R_new = R_old @ dR, x_new = x_old + R_old @ dx
  • Re-centering: translations are shifted to zero mean (center of mass = origin)
  • Option: stop_grad_frames = True — detach frames from gradient graph between layers
▼

8. Torsion Head

MLP + h_L skip → (sin, cos) unit circle

Predicts backbone torsion angles on the unit circle:

  • Input: final node representation h_L (from last IPA layer, with skip connection)
  • MLP projects to 2 × n_torsions values
  • Output: (sin θ, cos θ) pairs — naturally lives on unit circle, avoiding angle wrapping issues
  • Used in frame2atom conversion: torsions + frames → all-atom coordinates
