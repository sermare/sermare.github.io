Key Finding

Zero-init LoRA ensures the model starts from the exact AF2 baseline. The B matrix is initialized to zero, so the LoRA output is zero at step 0 and the forward pass is identical to unmodified AF2. TTT improvements are real signal, not recovery from random initialization damage. However, step 0 DockQ matches the baseline for only 22/182 pairs due to stochastic elements in the pipeline (dropout, MSA sampling).
