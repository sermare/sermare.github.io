Method

Pipeline

Input: Paired MSA (A + B) | v AF2-Multimer (frozen) |-- Evoformer (48 blocks) | |-- MSA attention <-- LoRA (rank 4, zero-init) | |-- Pair stack <-- LoRA (optional, rank 4) | v TTT Loop (200 steps, Adam, lr=0.01) |-- Forward pass with MSA row masking |-- Masked MSA loss (cross-entropy) |-- Update LoRA weights only |-- Save checkpoint every 10 steps | v Checkpoint Selection |-- Evaluate DockQ at each checkpoint |-- Select best by confidence function | v Output: Predicted complex structure
