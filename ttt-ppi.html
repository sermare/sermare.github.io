Key Findings

TTT as rescue:
For pairs where AF2 baseline fails (DockQ < 0.1), lr=0.05 TTT gives +0.25–0.35 DockQ, pushing many to acceptable quality. 12 additional pairs cross the DockQ=0.23 threshold.
TTT hurts strong predictions:
For pairs AF2 already solves (DockQ > 0.3), TTT degrades quality — the loss divergence pattern destroys good structure. 1EZU drops from 0.951 to 0.359, 1FFW from 0.611 to 0.104.
Practical use:
Run baseline first. If DockQ proxy (ipTM) is low, apply TTT. If already confident, skip TTT. This selective strategy could achieve the best of both worlds.
