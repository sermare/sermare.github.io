Where do improvements peak? (200s constant, n=32)

81% of genuine improvements peak after step 50. Mean peak: step 104.

200 steps rescues non-responders

4 pairs rescued from zero improvement at 50 steps: 1ACB +0.036, 1CGI +0.065, 1D6R +0.041, 1AHW +0.025. 85% success rate vs 28.5% at original 50 steps.

Cosine beats constant LR

Head-to-head: 5/6 wins for cosine. More consistent, fewer collapses. Constant occasionally gets large spikes (1GCQ +0.182) that cosine misses.

ipTM is a broken selector

ipTM captures -2.1% of oracle gain (net negative). 25/186 pairs degraded by ipTM selection. Contact count (8A) outperforms it.

Collapse Analysis

Pair stack LoRA at lr=0.01 collapses 3/3 (same failure mode as MSA at lr=0.05). Triangular attention modules are more sensitive to perturbation than MSA attention. Reducing to lr=0.005 eliminates collapse for pair stack.

In 200s constant: 3/34 collapse (9%), all with bad_bonds >= 25 and COM distance < 8A. Cosine annealing: 0/11 collapses.

Method

Pipeline

Input: Paired MSA (A + B) | v AF2-Multimer (frozen) |-- Evoformer (48 blocks) | |-- MSA attention <-- LoRA (rank 4, zero-init) | |-- Pair stack <-- LoRA (optional, rank 4) | v TTT Loop (200 steps, Adam, lr=0.01) |-- Forward pass with MSA row masking |-- Masked MSA loss (cross-entropy) |-- Update LoRA weights only |-- Save checkpoint every 10 steps | v Checkpoint Selection |-- Evaluate DockQ at each checkpoint |-- Select best by confidence function | v Output: Predicted complex structure
